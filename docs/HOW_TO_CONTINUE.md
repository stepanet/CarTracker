# Как продолжать работу над CarTracker

Инструкция для возобновления работы после прерывания сессии с ИИ-ассистентом.

---

## 🎯 Главный принцип

ИИ **не помнит** прошлые чаты. Всё критичное должно жить в репозитории, а не в переписке.

Перед началом нового чата соберите «пакет контекста» из этого файла, README.md и AI_CONTEXT.md.

---

## 📋 Что делать при каждом новом чате

### Шаг 1. Откройте эти файлы

- `README.md` — что уже реализовано
- `AI_CONTEXT.md` — архитектура и соглашения
- `CHANGELOG.md` — история изменений
- `docs/WIP.md` — если есть незавершённая фича

### Шаг 2. Соберите текущий код

Варианты:

**A. Публичный репозиторий (самый удобный):**
Просто дайте ссылку: https://github.com/stepanet/CarTracker
