# Changelog

## [1.0] — 2026-09-21

Первый релиз. Учёт работ, статистика, напоминания о ТО.

### Added
- **Учёт работ:**
  - Модель `CarWork` с категориями (ТО, ремонт, шины, топливо, страховка, прочее)
  - `CarWorkStore` с сохранением в UserDefaults
  - Список работ с поиском и фильтром по категориям
  - Экран добавления / редактирования
- **Статистика:**
  - Сводка «Всего / За год / Средний в месяц»
  - График расходов по месяцам (Swift Charts, BarMark) с переключением 3/6/12 мес
  - Круговая диаграмма по категориям (SectorMark) с легендой
- **Напоминания о ТО:**
  - Модель `Reminder` с интервалами по км и месяцам
  - `ReminderStore` + `ReminderCalculator` (логика статусов 🟢🟡🔴⚪)
  - Экран «Напоминания» со сводкой и сортировкой по статусу
  - Красивая карточка с прогресс-баром и блоком «Последнее → Следующее»
  - Экран добавления / редактирования с палитрой иконок
  - Локальные уведомления (`UserNotifications`)
  - Баннер «Включите уведомления» при отказе
  - Типовой набор из 4 базовых напоминаний
- **Архитектура:**
  - MVVM: Models / ViewModels / Views
  - Три вкладки в `TabView`
  - Документация: README, CHANGELOG, AI_CONTEXT

### Technical
- Swift 5.9+, SwiftUI, Swift Charts
- Минимальная версия iOS: 16.0
- Хранение: JSON → UserDefaults
