# Changelog

## [2.0] — 2026-09-24

Облачная синхронизация через Supabase. Единая база с веб-версией.

### Added

**🔐 Аутентификация (Supabase Auth)**
- Экран входа / регистрации `AuthView`
- `AuthManager` — управление сессией (сохранение в Keychain)
- Русские сообщения об ошибках
- Валидация email + пароля
- Кнопка «Выйти» в шапке `ContentView`
- Email пользователя в шапке

**☁️ Синхронизация данных (Supabase)**
- `SupabaseService` — единый клиент Supabase
- `WorksRepository` — CRUD работ + подработ
- `RemindersRepository` — CRUD напоминаний
- `RealtimeManager` — Realtime-подписки (WebSocket)
- Оптимистичные обновления UI с откатом при ошибке
- Миграция UserDefaults → Supabase (одноразовая)
- Pull-to-refresh в списках работ и напоминаний
- Автоперезагрузка данных при возврате в фокус

**🛠 Технические улучшения**
- Кастомный `init(from:)` в `CarWork` — совместимость со старыми бэкапами
- `replica identity full` для Realtime DELETE
- Синтаксис фильтров `.eq("user_id", value: ...)`
- `subscribeWithError()` вместо `subscribe()`

### Changed
- `CarWorkStore` — Supabase вместо UserDefaults
- `ReminderStore` — Supabase вместо UserDefaults
- Все CRUD-методы в сторах стали `async`
- `ContentView` получил верхнюю панель с email и кнопкой выхода

### Fixed
- Порядок хуков в SwiftUI-вью
- Тип `user` narrowing в async-контексте
- Отсутствующие импорты (`Auth`, `UniformTypeIdentifiers`)
- Realtime DELETE: события не приходили (исправлено через `replica identity full`)

### Notes
- Облачная база **общая с веб-версией:** https://car-tracker-web-pi.vercel.app
- Формат JSON-бэкапа совместим
- Realtime работает для INSERT / UPDATE / DELETE
- Supabase SDK: `supabase-swift` 2.x

## [1.2] — 2026-09-22

Фоновая проверка напоминаний. Уведомления приходят без открытия приложения.

### Added
- `BackgroundTaskManager` — менеджер фоновых задач
- `BGAppRefreshTask` с идентификатором `com.cartracker.app.refresh`
- Регистрация задачи при старте приложения (`init()`)
- Планирование задачи при уходе в фон (`scenePhase == .background`)
- Пересчёт уведомлений в фоне (без запуска UI)
- Background Modes capability: `fetch` + `processing`
- `BGTaskSchedulerPermittedIdentifiers` в Info.plist

### Notes
- iOS не гарантирует точное время запуска — задача может выполняться раз в день или реже
- Полностью закрытое свайпом приложение не получает фоновые задачи (ограничение iOS)
- Тестировать лучше на реальном устройстве или через `_simulateLaunch` в отладчике

## [1.1] — 2026-09-22

Экспорт и импорт данных. Резервные копии и перенос между устройствами.

### Added
- Модель `BackupData` — обёртка для сериализации бэкапа (version, exportedAt, works, reminders)
- `BackupManager`:
  - Экспорт бэкапа в JSON (pretty-printed, ISO8601 даты)
  - Импорт бэкапа с проверкой версии
  - Объединение данных без дубликатов (по `id`)
  - Экспорт работ в CSV (разделитель `;`, BOM для Excel)
- UI на экране «Работы»:
  - Кнопка «...» в тулбаре с меню
  - Пункты: «Экспорт бэкапа», «Экспорт в CSV», «Импорт из файла»
  - `ShareSheet` (обёртка над `UIActivityViewController`)
  - `fileImporter` для выбора файла
  - Alert с результатом импорта
- Метод `replaceAll(with:)` в `CarWorkStore` и `ReminderStore`

### Notes
- iCloud-синхронизация отложена до платного Apple Developer Program
- Импорт работает в режиме «объединение» — существующие данные не удаляются

## [1.0] — 2026-09-21

Первый релиз. Учёт работ, статистика, напоминания о ТО.

### Added
- **Учёт работ:**
  - Модель `CarWork` с категориями (ТО, ремонт, шины, топливо, страховка, прочее)
  - `CarWorkStore` с сохранением в UserDefaults
  - Список работ с поиском и фильтром по категориям
  - Экран добавления / редактирования
- **Статистика:**
  - Сводка «Всего / За год / Средний в месяц»
  - График расходов по месяцам (Swift Charts, BarMark) с переключением 3/6/12 мес
  - Круговая диаграмма по категориям (SectorMark) с легендой
- **Напоминания о ТО:**
  - Модель `Reminder` с интервалами по км и месяцам
  - `ReminderStore` + `ReminderCalculator` (логика статусов 🟢🟡🔴⚪)
  - Экран «Напоминания» со сводкой и сортировкой по статусу
  - Красивая карточка с прогресс-баром и блоком «Последнее → Следующее»
  - Экран добавления / редактирования с палитрой иконок
  - Локальные уведомления (`UserNotifications`)
  - Баннер «Включите уведомления» при отказе
  - Типовой набор из 4 базовых напоминаний
- **Архитектура:**
  - MVVM: Models / ViewModels / Views
  - Три вкладки в `TabView`
  - Документация: README, CHANGELOG, AI_CONTEXT

### Technical
- Swift 5.9+, SwiftUI, Swift Charts
- Минимальная версия iOS: 16.0
- Хранение: JSON → UserDefaults
