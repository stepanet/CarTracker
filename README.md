## 🌐 Как работает синхронизация

- **Supabase (PostgreSQL)** — облачная база данных
- **Supabase Auth** — аутентификация
- **Supabase Realtime** — мгновенная синхронизация через WebSocket
- **Row Level Security (RLS)** — каждый пользователь видит только свои данные

**Один аккаунт** — для iOS и веб-версии. Заходите с любого устройства, данные всегда актуальны.
