# CarTracker — учёт работ по автомобилю

iOS-приложение на SwiftUI для учёта работ, расходов и статистики по машине.

## Статус (обновлено: 2026-09-21)

**Текущая версия: v1.0** ✅

### ✅ Реализовано
- [x] Модель CarWork (название, категория, дата, пробег, стоимость, заметки)
- [x] CRUD: добавление / редактирование / удаление
- [x] Сохранение в UserDefaults (JSON)
- [x] Фильтр по категориям + поиск
- [x] Сводная статистика (всего / за год / среднее в месяц)
- [x] График расходов по месяцам (Swift Charts, BarMark)
- [x] Круговая диаграмма по категориям (SectorMark)
- [x] TabView: Работы | Статистика | Напоминания
- [x] Напоминания о ТО
  - [x] Модель Reminder (название, иконка, интервалы км/мес)
  - [x] ReminderStore + логика статусов (🟢🟡🔴⚪)
  - [x] Красивая карточка с прогресс-баром
  - [x] Экран добавления/редактирования с выбором иконки
  - [x] Локальные уведомления (UserNotifications)
  - [x] Запрос разрешения при первом запуске
  - [x] Пересчёт уведомлений при возврате из фона
  - [x] Типовой набор из 4 напоминаний
  - [x] Экспорт / импорт данных
  - [x] Экспорт бэкапа в JSON (все работы + напоминания)
  - [x] Экспорт работ в CSV (для Excel / Numbers)
  - [x] Импорт бэкапа с объединением (дубликаты по id пропускаются)
  - [x] Показ статистики импорта (добавлено / пропущено)
  - [x] Share sheet: AirDrop, Mail, iCloud Drive, Google Drive
  - [x] Фоновая проверка напоминаний
  - [x] `BGTaskScheduler` с `BGAppRefreshTask`
  - [x] Планирование раз в ~6 часов (earliestBeginDate)
  - [x] Пересчёт уведомлений без открытия приложения
  - [x] Регистрация задачи при старте
  - [x] Перепланирование при уходе в фон
