# CarTracker — учёт работ по автомобилю

iOS-приложение на SwiftUI для учёта работ, расходов и статистики по машине.

## Статус (обновлено: 2026-09-21)

### ✅ Реализовано
- [x] Модель CarWork (название, категория, дата, пробег, стоимость, заметки)
- [x] CRUD: добавление / редактирование / удаление
- [x] Сохранение в UserDefaults (JSON)
- [x] Фильтр по категориям + поиск
- [x] Сводная статистика (всего / за год / среднее в месяц)
- [x] График расходов по месяцам (Swift Charts, BarMark)
- [x] Круговая диаграмма по категориям (SectorMark)
- [x] TabView: Работы | Статистика

### 🚧 В планах
- [ ] Несколько автомобилей
- [ ] Напоминания о ТО (UserNotifications)
- [ ] Экспорт в CSV / PDF
- [ ] Фото чеков (PhotosPicker)
- [ ] Синхронизация через iCloud (CloudKit / SwiftData)
- [ ] Сравнение расходов по годам

## Технологии
- Swift 5.9+, SwiftUI
- Swift Charts (iOS 16+)
- UserDefaults (простая персистентность)
- Минимальная версия iOS: 16.0
